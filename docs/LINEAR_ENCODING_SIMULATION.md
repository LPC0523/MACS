# 线性编码仿真

本页面用于离线估算多通道线圈在指定区域内产生的时变空间场。它不会连接串口或扫描仪，也不代表功放能够实际复现所显示的波形。

## 快速使用

1. 选择线圈配置，并核对场图单位为 `Hz/A`。
2. 选择球形 DSV 或被试 ROI，点击“计算区域与覆盖率”。
3. 选择编码方向、波形、幅度、频率和持续时间。
4. 设置方向锥 `θ`、非线性容差 `ε` 与超限策略。
5. 点击“运行离线仿真”，在结果和可视化页查看输出。
6. 使用“导出”保存 JSON、CSV 与 Markdown 报告。

## 两种模式

### 目标梯度波形

软件先在当前 ROI、方向和约束下求可达的线性场模式，再按用户指定的时间波形生成各通道电流。页面分别报告请求幅度、模型上界和实际模型幅度。

### 直接通道电流

第一版仅支持 CSV。第一列为 `time_s`，其余列依次为各通道电流，单位 A。该模式不优化场形，`θ` 和 `ε` 不参与求解。

## 坐标和单位

- 线圈场图：Hz/A。
- 梯度：Hz/m，并可换算为 mT/m。
- 电流：A。
- 相位：rad。
- 理想化 k 偏移：cycles/m。
- 空间方向来自 NIfTI affine 的 RAS 世界坐标。

本项目没有可靠读取 `PatientPosition` 和 `PhaseEncodingDirection`，因此 RAS-Y 不能直接称为扫描仪相位编码方向。斜切 affine 显示的是 native voxel plane，不等于标准正交解剖平面。

## 场分解

每个通道场被分为：

- 常数分量：不携带空间位置信息；
- 线性分量：可表示为常规线性 k 偏移；
- 非线性空间分量：同样可以携带空间信息，但不能表示为单一笛卡尔 k 向量，需要序列前向模型和模型化重建。

## 约束

`θ_max` 限制实际线性梯度偏离目标方向的角度；`ε_nonlinear` 限制非线性空间场相对于目标线性场的比例。二者描述不同问题，不能只用一个总 NRMSE 代替。

每通道电流限制为 ±3 A。静态匀场电流与动态电流相加后逐采样检查：

- `reject`：任何采样越界即拒绝；
- `uniform scale`：用同一个比例整体缩放动态波形；
- 不使用逐采样 clipping，因为它会改变波形、相位和积分结果。

## DSV 覆盖率

理论球体素数和有效体素数在同一个扩展离散晶格上计算。覆盖率低于 95% 时显示 `TRUNCATED`，此时区域是“球形区域 ∩ 有效标定范围”，不能作为完整 DSV 的模型能力结论。

## 波形

支持 sine、cosine、triangle、trapezoid、square、piecewise-linear 和自定义 CSV。方波不带限；其理想积分可以数值收敛，但真实边沿、`di/dt`、感应电压和放大器响应不在当前模型中。

## 可视化含义

- `k_dynamic`：新增动态 B0 线性分量积分得到的理想化 k 偏移；
- `k_total_local_model`：本地线圈静态与动态线性分量的总和；
- 二者均不包含扫描仪内置成像梯度，不是完整扫描序列的 k-space 轨迹；
- 非线性空间场仅显示场和相位，不进入单一 k 曲线。

空间场和相位切面按需生成当前时间点，不创建四维场数组。色标为当前帧以零为中心的对称自动范围，因此不同时间点的颜色强弱不能直接作绝对比较。

## 尚未建模

以下项目当前均为 unknown：

- 线圈电阻与自感；
- 通道互感；
- 放大器电压上限和带宽；
- 传递函数 `H(f)`；
- 扫描仪 ADC 和梯度时序同步；
- 系统内置梯度对多通道线圈的感应耦合；
- 真实 EPI 序列与图像重建。

因此，本页面只能说明理想线性电流模型中的空间场可达性，不能据此宣称硬件可实现、EPI 加速或图像改善。
